НОМЕРОК 0.1 — распознавание автомобильных номеров РФ (прототип)
================================================================

Работает полностью офлайн, на процессоре, без установки. Windows 10/11 x64.

ЧТО УМЕЕТ
- Фото (jpg, png, bmp, webp) и целые папки с фото.
- Видеофайлы (mp4, avi, mkv, mov...) — с отслеживанием машин: номер
  собирается «голосованием» по нескольким кадрам и выводится один раз.
- IP-камеры по RTSP/HTTP — работает непрерывно, переподключается сам.
- Проверка формата РФ (А123ВС 77 / 777, такси, прицепы, мото, полиция,
  транзит) и кода региона; спорные символы О/0, В/8 исправляются по формату.
- Поиск по списку: подсветка нужных номеров («СОВПАДЕНИЕ»).
- Отчёт: report.html (с фото номеров и кадрами), plates.csv (открывается
  в Excel), plates.jsonl (для программ), видео с рамками (по желанию).

БЫСТРЫЙ СТАРТ
1. Распакуйте архив в любую папку (все файлы должны лежать вместе).
2. Перетащите фото, папку или видео на nomerok.exe.
   Или запустите nomerok.exe и вставьте путь.
3. В конце откроется отчёт. Результаты — в папке «<имя>_nomerok» рядом
   с исходником.

ВИДЕО И КАМЕРЫ: НУЖЕН FFMPEG (один раз)
  Вариант А: в командной строке  winget install Gyan.FFmpeg
  Вариант Б: скачайте ffmpeg-release-essentials.zip с
             https://www.gyan.dev/ffmpeg/builds/  и положите ffmpeg.exe
             рядом с nomerok.exe (или папку ffmpeg\bin).
  Для фото ffmpeg не нужен.

КОМАНДНАЯ СТРОКА
  nomerok.exe C:\фото\
  nomerok.exe запись.mp4 --video
  nomerok.exe запись.mp4 --find "А123ВС77,К777ОО197"
  nomerok.exe запись.mp4 --find список.txt
  nomerok.exe "rtsp://admin:пароль@192.168.1.64:554/Streaming/Channels/101"

  Примеры адресов камер:
    Hikvision: rtsp://логин:пароль@IP:554/Streaming/Channels/101  (102 — доп. поток)
    Dahua:     rtsp://логин:пароль@IP:554/cam/realmonitor?channel=1&subtype=0
    Другие:    адрес обычно есть в инструкции или в VLC «Открыть URL».
  См. файл «camera_example.bat» — поправьте в нём адрес (откройте Блокнотом) и запускайте двойным щелчком.

  Параметры:
    -o ПАПКА        куда сохранить результат
    --fps N         сколько кадров в секунду анализировать (6)
    --sure X        порог «уверен», 0–1 (0.7)
    --find СПИСОК   искать номера (через запятую или файл .txt)
    --video         сохранить видео с рамками (annotated.mp4)
    --det-conf X    порог поиска номеров (0.3); меньше — находит дальние,
                    но больше ложных
    --gap С         через сколько секунд без номера машина «уехала» (1.5)
    --repeat С      не повторять тот же номер чаще, чем раз в С секунд (20)
    --threads N     сколько ядер процессора использовать (все)
    --no-open       не открывать отчёт в конце
  Полный список: nomerok.exe --help

ТОЧНОСТЬ (замеры на прототипе)
- Чтение номера по вырезанной табличке: 99,7 % без единой ошибки
  (2 845 тестовых номеров AUTO.RIA, которые модель не видела).
  Исходная «общемировая» модель на тех же данных — 63 %.
- Реальные фото с улиц (Wikimedia Commons, 51 снимок): из 27 сверенных
  вручную гражданских номеров верно прочитано 26.
- Скорость на 2 ядрах: ~0,2 с на фото, видео ~8 кадров/с анализа
  (при --fps 6 этого хватает на одну камеру в реальном времени).
  На 4–8 ядрах — пропорционально быстрее.
- Каждый номер получает «уверенность»; ниже порога он помечен
  «не уверен» — такие стоит проверить глазами в отчёте.

ОГРАНИЧЕНИЯ ПРОТОТИПА
- Обучено на обычных белых номерах. Чёрные военные, дипломатические
  (красные), двухстрочные (мото, прицепы) и «блатные» с буквами
  вне ГОСТа читаются плохо или никак.
- Мелкие номера (уже ~60 пикселей по ширине), сильный наклон, ночь/ИК,
  грязь и блики снижают точность. Лучше всего — камера, направленная
  на въезд, номер 120+ пикселей шириной.
- Не проверялось на реальной Windows-машине (собрано кросс-компиляцией),
  exe не подписан — SmartScreen может спросить «Всё равно запустить».

ДООБУЧЕНИЕ ПОД СВОЮ КАМЕРУ
  Папка train\ — модель, конфиги и команды (см. train\HOWTO_TRAIN_ru.txt).
  Новую модель кладите в models\ocr.onnx + models\ocr.yaml рядом с exe —
  программа подхватит её вместо встроенной (аналогично models\detector.onnx).
